# Desktop admin handoff

The **Admin — Desktop** page is an editable native Penpot design in the existing file. It extends the mobile admin feature set documented in [ADMIN_FEATURES.md](../ADMIN_FEATURES.md). The 31 mobile admin boards and public designs are retained.

- Main application boards: 1440×1000, with persistent side navigation, a top header, wide tables and paired task/detail regions.
- Dialogs: 640px wide, centered in prototype examples, with explicit context and cancel/confirm actions.
- Content and billing rules remain those in [admin-mobile-rules.md](admin-mobile-rules.md). A desktop layout does not change fee deadlines, balance calculations, reminder eligibility, archive behavior or attendance rules.
- Samples use October 30, 2026 in Asia/Karachi. All names, figures, fees, phones, receipts and message outcomes are demonstration content.
- Prototype links illustrate selected paths. Native fields and actions do not provide a database, live validation, fee engine, payment submission or WhatsApp delivery. No messages were sent.
- The reference board contains 29 validation/recovery examples. Chart values, labeled statuses, exclusions and result categories remain explicit.

The [manifest](admin-desktop-manifest.json) records all 47 root boards, native IDs, dimensions, counts, structural checks, previews and review scope. There are 17 final PNG previews and a [contact sheet](admin-desktop-contact-sheet.jpg). The independent full review covered 13 representative views and the structural manifest; the verdict pass confirmed the sole copy fix resolved across five recaptured views.
